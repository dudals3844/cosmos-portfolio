## 배포

GitHub Pages Source는 GitHub Actions로 설정합니다. main 브랜치에 commit 후 push하면 .github/workflows/pages.yml이 자동 배포합니다.

HTML·CSS·JavaScript·Canvas·WebGL로 구성하며 별도 서버가 필요하지 않습니다. 그래프와 구조도는 설명용이며, 전략 결합 곡선은 실제 운용 성과가 아닌 개념도입니다.

## 공개 파일과 보안 정책

`scripts/prepare-site.py`가 허용 목록에 있는 파일만 `_site/`에 복사하며, Pages는 이 결과만 배포합니다. 문서·백업·인증 파일을 배포 경로에 추가하지 마세요. 배포 액션은 전체 커밋 SHA로 고정하고 checkout 인증정보를 유지하지 않습니다.

페이지의 meta CSP는 자체 JavaScript만 허용하고 API 연결·폼 제출·임베드를 차단합니다. 애니메이션을 위해 인라인 스타일은 허용하며, 글꼴은 Google Fonts를 사용합니다.

연구 개선 사례와 연구 시스템 소개는 하나의 스크롤 그래프로 통합했습니다. `research-case.js`는 기대 경로 → 경로 이탈 → RAG 검색 → Workflow 연구·구현·검토 → Backtest MCP 측정 → 기록·운영의 여섯 장면을 스크롤 위치에 맞춰 표시합니다. 되돌아 스크롤하면 앞 장면을 다시 볼 수 있고, 작은 화면에서는 진행하는 점을 따라 그래프 화면이 이동합니다. 모션 끄기·동작 줄이기에서는 정적 설명으로 표시합니다. 그래프는 cosmos-agent의 thinker-new-strategy Workflow와 독립 평가 파이프라인의 분기·복귀 경계를 요약한 개념도이며 실시간 상태가 아닙니다.

연구 그래프는 자료 탐색 → 가설·구현 → 측정·평가 → 기록·운영의 네 핵심 단계로 간소화했습니다. Backtest MCP 측정은 해당 스크롤 장면에서만 표시하고, 세부 테스트·산출물·리뷰는 가설·구현 단계로 묶었습니다. 수정 경로는 하나로 요약합니다.

연구 여정은 여섯 페이지이며, 세 번째 페이지가 논문이 RAG로 모이는 장면("그래서 먼저, 자료 수집부터 구조화했습니다")입니다. 경로 이탈(2) 뒤에 고정된 그래프 위로 이 장면이 올라와 덮었다가 지나가면, 그래프는 Workflow(4)에서 이어집니다. 완성된 블랙홀은 스크롤 약 한 화면 동안 머문 뒤 넘어갑니다. 모션을 끈 정적 화면에서는 그래프 다섯 페이지를 먼저 한 번에 보여 주고 그 아래에 이 장면을 둡니다. `paper-blackhole.js`가 WebGL 점 파티클로 와이어프레임 논문과 먼지 원반을 그리고, 스크롤에 따라 논문이 나선으로 빨려 들어가며 같은 입자들이 광자 고리·헤일로·기울어진 강착원반의 블랙홀 형상으로 모입니다. 장면은 논문 순환 → RAG로 흡수 → 근거 문단·출처 반환의 세 단계이며, 출처 표기(SSRN · Journal of Finance · arXiv)와 근거 예시는 설명용입니다. 타임라인·입자 배치 같은 순수 계산은 `paper-orbit.js`에, 여정의 스크롤 위치 → 장면 계산은 `research-journey.js`에 분리했고 `node --test tests/`로 검증합니다. 모션 끄기·동작 줄이기·WebGL 미지원 환경에서는 정적 설명으로 표시합니다.

이스터에그로, 위에서 내려올 때는 보이지 않고 아래에서 블랙홀 장면으로 다시 올라오면 "근거 문단 · 출처 Journal of Finance" 칸 아래에 "🚀 블랙홀 탈출 해보기" 버튼이 나타납니다. 버튼을 누를 때만 `paper-escape.js`가 짧은 탈출 장면을 재생합니다(자동 재생하지 않습니다). 세워진 바퀴 모양 우주선(직접 그린 SVG) 가운데 창에는 아멜리아(검은 말티즈)가 타고, 그 위에 쿠퍼(우주비행사)와 TASS(작은 로봇)의 셔틀 두 대가 붙어 있습니다. 우주선은 원반과 같은 기울기로 블랙홀 주위를 3차원으로 돌다가 중심 뒤로 가면 그림자에 가려집니다. 블랙홀 오른쪽에서 TASS가 "3, 2, 1, 분리"를 세고 셔틀을 분리해 빨려 들어가며, 아멜리아("굿바이 TASS")와 작별 인사를 나누고("굿바이 브랜드 박사님, 반대쪽에서 뵙죠 쿠퍼") 쿠퍼가 "그러자고"라고 답합니다. 잠시 뒤 쿠퍼가 "분리준비"를 하자 아멜리아가 "쿠퍼 무슨 짓이에요?"라고 묻고, 쿠퍼는 "잊었어, 아멜리아? 90%만 솔직하기."라고 답한 뒤 블랙홀 가운데에서 분리되어 빨려 들어갑니다. 두 셔틀은 다시 나오지 않고, 가벼워진 바퀴 우주선만 부스터로 탈출합니다. 재생하는 동안 화면 위아래에 영화 같은 검은 띠가 나타나고, 끝나면 버튼이 다시 보입니다. 궤적·대사 순서는 DOM 없이 `node --test`로 검증하며, 모션 끄기·동작 줄이기에서는 재생하지 않습니다. 블랙홀의 빛 휘어짐은 그림자 위의 아치와 아래의 그릇 모양으로 그리고(`lensPoint`), 원반은 수평을 유지한 채 앞뒤로만 기울입니다.

지원 포트폴리오의 구성은 인사·경력·창업 배경·연구 과정·전략 결합·Agent 운영·마무리입니다. 데이터 수집·처리와 주문 실행·관리의 독립 장면은 제거했습니다.

감사 인사로 본편을 마친 뒤, 선택 안내를 따라 더 스크롤하면 상추 생산자와 음식점의 미래 거래 조건 합의를 설명하는 보충 아이디어를 볼 수 있습니다. `appendix-idea.js`와 `appendix-idea.css`가 걱정 → 조건 합의 → 시세와 약속 가격 비교 → 불확실성 완화의 네 장면을 표시합니다. 본편 챕터 수·꽃 재결합 시점은 유지하며, 본편 진행률은 감사 인사에서 완료됩니다. 실제 거래를 수행하지 않는 구상 예시입니다.

아이디어 01은 선물거래의 위험관리 발상을 일상 구매에 적용하는 제안으로 소개합니다. 농부·고깃집의 걱정을 먼저 보여준 뒤, 스마트스토어와 비슷한 독립 구매 화면에서 1달 뒤 → 2달 뒤 화요일 수령일 선택, 물량·예약 가격 확인, 농부가 미리 등록한 조건으로 예약하고 출하를 준비하는 흐름으로 이어집니다. 수령일 버튼은 설명용 상호작용이며 실제 주문이나 네이버 연동을 실행하지 않습니다.

사회문제 예시는 아이디어 01(동네 음식점의 미사용 식재료 AI 매칭·거래 수수료)과 아이디어 02(농부가 등록한 미래 물량·가격의 예약구매) 순서입니다. `inventory-idea.js`는 A 주식이라는 가상 종목의 100원·101원 가상 호가에서 빈 주문 자리 → 매수 주문 추가 → 체결 → 매도 1호가 추가 → 체결 → 비용 차감 전 차이 1원 표시를 한 번 재생하고 결과에 멈춥니다. 이후 식재료 조건 비교, AI 후보 연결, 매도자·매수자 수수료 정산 예시로 이어집니다. 가격·수수료는 설명용 가정이며 실제 거래를 수행하지 않습니다.

아이디어 01의 모션은 최우선 매수·매도 자리만 보여줍니다. 주문 블록이 100원에 차오르고 체결된 뒤, 매수한 1주가 화살표를 따라 101원 매도호가에 올라가 체결됩니다. 호가창이 사라진 다음 비용 차감 전 1원 차이를 표시합니다. 한 번 재생 후 유지하고 다시 보기 버튼을 제공합니다. 식재료 매칭은 음식점·AI 아이콘으로 표시하며, 거래 체결과 수수료 안내도 계산표 대신 모션으로 요약했습니다.

프로젝트 명칭은 Cosmos로 통일했습니다. 앞부분은 진행해 온 연구·운영 프로젝트를 소개하고, 마무리는 Cosmos에서 쌓은 경험을 바탕으로 SK AIGEN에서 다른 분야의 동료와 문제를 탐색하는 방향으로 연결합니다.

아이디어 01의 스프레드 수익·Market Making 강의 모션을 삭제하고 같은 상품의 주문 조건을 짧게 비교하는 예시로 바꿨습니다. 소개는 시장 설계·가격 발견에서 착안한 비표준 재고 매칭으로 정리하며, 실제 제안 모델은 직접 매입이 아닌 거래 연결·수수료 중개입니다.
